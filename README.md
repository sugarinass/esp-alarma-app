# Охрана мастерской

Веб-приложение (PWA) для сигнализации ESP_ALARMA на ESP32-C3: режим, постановка и снятие,
снимки с камер, лента событий. Связь с устройством идёт через ntfy.sh, все команды
подписаны HMAC-SHA256. Секреты в репозитории не хранятся: строку привязки устройство
выдаёт командой `pair`, она сохраняется только в браузере телефона.
